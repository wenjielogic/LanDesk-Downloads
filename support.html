LanDesk 局域桌面

在同一局域网，用 iPhone 查看并轻量操作自己的 Windows 电脑。

先在 Windows 电脑上准备好

LanDesk 的 iPhone 应用需要配套电脑端。手机连接 Wi-Fi，Windows 电脑可使用 Wi-Fi 或网线；两台设备需要处于可互通的同一 IPv4 子网。运行和配对不需要云账户或互联网中转。首次下载需要互联网。

第一次连接

  1. 打开电脑端，选择手机所在网络对应的网卡。如果要操作电脑，先勾选“允许已配对手机使用鼠标和键盘”。默认仅查看。
  2. 点击“开始共享”。首次出现 Windows 防火墙提示时，只允许你选择的可信专用网络；不要开放公网或做路由器端口映射。
  3. 在 iPhone 打开局域桌面，允许局域网访问，扫描电脑显示的二维码。相机权限只用于扫码；也可以使用“粘贴”按钮粘贴完整连接码。
  4. 电脑出现连接请求后，核对并批准。每个二维码最多有效 10 分钟，成功配对后失效，一次只连接一台手机。不要把有效二维码公开分享。
  5. 手机显示电脑主屏。默认“调整画面”：拖动和双指缩放只改变手机观看位置。“复位画面”恢复完整视图。
  6. 切换“鼠标操作”后，点击、拖动、双指滚动和长按右键才发送到电脑。电脑端未允许控制时，这些操作仍被禁止。
  7. 输入文字时，先点选电脑输入框，再点手机“键盘”，输入中文、英文或 emoji 后点击“发送”。回车、退格、Tab 和方向键有独立按钮。发送失败时请先检查电脑是否已经收到，App 不会自动重发。
  8. 结束时在手机点击“断开”，或在电脑停止共享。手机进入后台也会断开；重新连接需要重新配对。

连接失败怎么检查

  • 在 iPhone 的系统设置中允许 LanDesk 访问局域网。拒绝相机权限不影响粘贴连接码。
  • 手机与电脑要处于同一 IPv4 子网，且网络允许设备互通。2.4 GHz、5 GHz 和电脑网线可以混用，但取决于路由器设置；相同 Wi-Fi 名称也不保证互通。
  • 检查是否选错电脑网卡、使用访客网络、启用了设备隔离，或被专用网络的防火墙规则阻止。
  • 连接码过期、已使用、电脑停止共享或连接中断后，在电脑停止并重新开始共享，再扫描新码。
  • 想从仅查看改为可操作：先停止共享，勾选控制权限，再开始并重新配对。

当前功能范围

仅主显示器与普通桌面窗口。没有声音、文件传输、剪贴板同步、无人值守、后台控制、外网连接、云中转或 IPv6-only 支持。不保证操作锁屏、系统安全提示、管理员窗口或受保护视频。画面使用按需 JPEG 帧，适合查看桌面和轻量操作，不承诺游戏或流畅视频表现。电脑必须开机，电脑端必须保持运行。

Windows companion and setup

LanDesk lets an iPhone view and control the primary screen of a Windows PC on the same reachable IPv4 subnet. The Windows companion is required. The iPhone uses Wi-Fi; the PC can use Wi-Fi or Ethernet. No cloud account or internet relay is used. Internet access is needed to download the software, but not for local pairing and use.

The Windows companion is currently unsigned. Windows may show an unknown-publisher message. Check the download source and checksum; if your security policy blocks it, contact support or your administrator. Do not disable system security features.

  1. Run the Windows host and select the network interface shared with the iPhone. For control, select “允许已配对手机使用鼠标和键盘” (allow mouse and keyboard) before starting. View-only is the default.
  2. Select “开始共享” (start sharing). If Windows requests firewall permission, allow only the trusted private network you selected. Do not configure public internet forwarding.
  3. Open LanDesk on iPhone and allow local-network access. Tap “扫描电脑二维码” to scan the host QR. Camera permission is only for scanning; pasting the complete connection text is an alternative.
  4. Approve the pairing request on the PC. A code lasts up to 10 minutes and is consumed by successful pairing. One phone can connect at a time. Never publish a live pairing QR.
  5. “调整画面” adjusts the phone viewport: drag to pan, pinch to zoom, and use “复位画面” to reset. Switch to “鼠标操作” for pointer input. Tap for left click, drag, use two fingers to scroll, and hold for right click.
  6. For text, first select an input field on the PC. Tap “键盘” on iPhone, enter text, and tap “发送”. Separate controls provide Return, Backspace, Tab and arrow keys. Unconfirmed text is not automatically resent after a disconnect.
  7. Tap “断开” on iPhone or stop sharing on Windows to end the session. Moving the iPhone app to the background disconnects it. Pair again to reconnect.

If pairing fails

Check local-network permission, the selected Windows interface, the private-network firewall rule and router client isolation. Guest networks and separated VLANs can prevent communication. Wi-Fi bands do not need to match, but devices must be reachable on the same IPv4 subnet. Restart sharing to obtain a fresh code if it has expired or was already used. To enable control after a view-only session, stop sharing, enable the checkbox, and pair again.

Current scope

Primary monitor and ordinary desktop windows only. No audio, file transfer, clipboard sync, unattended access, background control, internet relay or IPv6-only support. Lock screens, secure system prompts, elevated windows and protected video are not guaranteed to work. On-demand JPEG frames are intended for light desktop use, not gaming or smooth video. The PC must remain on and the host must remain open.
